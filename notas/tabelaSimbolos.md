## Propriedades
- não há chaves repetidas
- NULL nunca é usado como chave
- NULL nunca é usado como valor associado a uma chave
## Sobre
Uma tabela de símbolos é uma tabela com duas colunas, uma chave e um valor.

Trata-se de uma TAD, pode ser implementada com um dicionário/map, bst, lista encadeada, etc.
