## Sobre
Skip list é uma lista encadeada ordenada onde cada nó possui uma quantidade variavel de links, sendo que o i-ésimo link implementa uma lista simplesmente encadeada que os  nós com menos i links.

uma analogia vaga: é uma busca binaria para lista encadeada
